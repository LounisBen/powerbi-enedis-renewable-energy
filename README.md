# Analyse des énergies renouvelables avec Power BI

## Présentation du projet

Ce projet Power BI analyse les installations de production d'énergie renouvelable en France ainsi que leurs performances territoriales.

L'objectif est de construire un rapport décisionnel permettant d'explorer les installations, les puissances installées et les différences entre régions et départements.

Une partie spécifique du rapport est consacrée à l'analyse du photovoltaïque et à sa mise en relation avec des données climatiques.

> Projet pédagogique réalisé dans le cadre de ma formation Data Analyst.

---

## Objectifs

Le rapport permet notamment de :

- suivre le nombre d'installations ;
- analyser la puissance installée ;
- comparer les performances par région et département ;
- analyser les différents types de production d'énergie ;
- identifier les départements les plus représentés ;
- étudier les installations photovoltaïques ;
- mettre en relation photovoltaïque, température et ensoleillement ;
- restituer les résultats sous forme de tableaux de bord interactifs.

## Structure du rapport

Le rapport est organisé en quatre pages principales.

### 1. Suivi de production d'énergie renouvelable

Vue générale permettant de suivre les principaux indicateurs :

- nombre total d'installations ;
- puissance totale installée ;
- nombre moyen d'installations par type de production ;
- puissance moyenne par région ;
- classement des principales régions ou zones selon les indicateurs étudiés ;
- évolution selon l'année sélectionnée.

---

### 2. Détail par région

Cette page permet d'approfondir l'analyse territoriale à partir d'une région sélectionnée.

Elle présente notamment :

- la puissance installée par département ;
- la puissance par type de production ;
- les départements comptant le plus d'installations ;
- une navigation permettant d'explorer les données régionales.

---

### 3. Analyse climatique et performance photovoltaïque

Cette page est consacrée aux installations photovoltaïques.

Elle permet d'étudier :

- le nombre d'installations photovoltaïques ;
- leur répartition géographique ;
- la température moyenne ;
- l'ensoleillement ;
- le rendement théorique ;
- les différences entre territoires.

---

### 4. Commentaires et recommandations

Une dernière page synthétise :

- les objectifs du rapport ;
- les principaux enseignements ;
- la valeur ajoutée de l'analyse ;
- les observations issues des données.
